^YBarePi Boot Loader^0

^WUp/Down^0 ...... move cursor
^WLeft/Right^0 ... move page
^WAlt+Left/Right^0 start/end
^W[A]^0 .......... run program
^W[X]^0 .......... directory up
^WAlt+[X]^0 ...... Screenshot

loading text *.TXT
	- text width = 40 characters
	- text height = 15 or 30 rows
	- ^^ is prefix of control characters
		^^^^ ... print ^^ character
		^^1..^^9 ... print character with code 1..9
		^^A..^^V ... print character with code 10..31
		^^0 ... normal gray text
		^^W ... white text
		^^X ... green text
		^^Y ... yellow text
		^^Z ... red text
		^^[ ... start invert
		^^] ... stop invert
